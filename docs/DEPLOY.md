# Deploying the simulator

The app is a static site (no server): `pnpm build` writes `apps/web/dist/`.
Weather comes straight from Open-Meteo in the browser; projects are stored in
the user's browser (IndexedDB) and exported as JSON files.

| Where                      | How                                                                                                                                                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **claude.ai preview link** | `pnpm build:artifact`, then publish `apps/web/dist-artifact/simulator.html` with the files in `files.json` (done by Claude after each phase). Weather search is blocked there; the simulation falls back to the clear-sky estimate. |
| **Netlify**                | New site from Git → pick the repository. `netlify.toml` sets the build and cache headers.                                                                                                                                           |
| **Vercel**                 | Import the repository. `vercel.json` sets the build and cache headers.                                                                                                                                                              |
| **GitHub Pages**           | Settings → Pages → Source: _GitHub Actions_; then Actions → _Deploy to GitHub Pages_ → _Run workflow_ (`.github/workflows/pages.yml`, builds with `--base /<repo>/`).                                                               |
| **Any web server**         | `pnpm build` and copy `apps/web/dist/` (any sub-path works: `pnpm --filter @solar-sim/web build --base /my/path/`). Serve `sw.js` and `index.html` with `Cache-Control: no-cache`.                                                  |

## Offline / install

Production builds include a service worker (`sw.js`, generated by
`apps/web/vite.config.ts`) and a web app manifest. After the first visit over
HTTPS the browser offers **Install** (desktop: address bar; Android: menu →
Install app; iPhone: Share → Add to Home Screen) and the app opens without a
network. Real weather needs the network; offline, choose the clear-sky estimate.
Each new deployment replaces the cached version on the next visit.
