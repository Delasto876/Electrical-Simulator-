| D-016               | Sun position: NOAA Solar Calculator algorithm (Meeus-based), UT used as TT.                                                                                                                                                | Brief asks for declination / equation of time / hour angle; ~0.01° accuracy is ample for shading and POA. | D-017               | Single-diode fit: for fixed (a, Rs) the Isc/Voc/MPP conditions are linear in (IL, I0, 1/Rsh), so they are solved exactly; the remaining dP/dV = 0 and βVoc conditions are solved in 2-D (grid seed + Levenberg–Marquardt). | A direct 5-D Newton/LM from pvlib-style initial guesses failed to converge on a 108-cell module. The reduced problem converged on every test module, ~20 ms per fit (cached per module in the UI). |
| D-018               | I(V) uses the explicit Lambert-W solution evaluated from ln(θ).                                                                                                                                                            | Avoids overflow for large arguments and avoids an inner iteration per point; also gives the analytic dI/dV used by the MNA companion model.                                                        |
| D-019               | Ambient ampacity correction uses the NEC 310.15(B)(1) square-root equation instead of the stepped table.                                                                                                                   | Permitted by the code, continuous in temperature, and reproduces the table factors (e.g. 0.87 at 45 °C for 90 °C wire).                                                                            |
| D-020               | Conductor sizing applies both NEC checks: unadjusted (terminal-column) ampacity ≥ 1.25 × Imax, and adjusted ampacity ≥ Imax; PV Imax = 1.25 × Isc.                                                                         | This is how "Isc × 1.25 × 1.25" in the brief is applied in practice (690.8(B)), shown step by step.                                                                                                |
| D-021               | MNA: dense Gaussian elimination, GMIN = 1e-12 S per node, PV companion model with a 5 V per-step voltage limit; batteries are Norton equivalents (no extra unknown).                                                       | Circuits are small (hundreds of nodes). Non-convergence is reported (`converged: false`), never silently returned.                                                                                 |
| D-022               | Element sign convention: current into terminal a; power is absorbed power (negative = delivering).                                                                                                                         | Standard passive sign convention; makes the Tellegen power-balance property test a simple Σp = 0.                                                                                                  |
| D-023               | Recharts 3 for charts.                                                                                                                                                                                                     | Named in the brief; declarative, works with React 19.                                                                                                                                              |
| D-024               | Only the NEC-generic code profile ships in Phase 1. IEC-generic and Jamaica follow with string sizing (Phase 3).                                                                                                           | The IEC profile needs IEC 60364-5-52 ampacity tables (a separate table family).                                                                                                                    |
| D-025 **(user)**    | Organise the code so each kind of change has one home; `docs/CHANGE_GUIDE.md` maps changes to files.                                                                                                                       | User request for Phase 2: "when I want to change something it's not digging through the whole code".                                                                                               |
| D-026 **(default)** | Default display units metric (mm/m) with AWG wire; default roof corrugated metal, mono-pitch, south-facing.                                                                                                                | Offered before Phase 2; user did not choose, so the offered defaults apply. One line each in `config/defaults.ts`; units toggle in the toolbar.                                                    |
| D-027               | Arrays are parametric: an `ArrayInstance` stores choices (module, rows × cols, rail, attachment, legs, tilt…); every rail, clamp, foot and leg is derived by the engine on each change, not stored.                        | Changing tilt/module/rail updates all hardware consistently; the saved file stays small; BOM and 3D can't drift apart.                                                                             |
| D-028               | Rail cutting picks the least-waste combination of stock lengths (exhaustive), ties broken by fewer splices.                                                                                                                | Greedy longest-first wasted 1564 mm on a 4.74 m run vs 964 mm for 3.6 + 2.1 m.                                                                                                                     |
| D-029               | Flush arrays use two cross rails per row at the middle of the module's clamping zone; landscape on cross rails with a long-edge-only module is an error.                                                                   | Matches common installation manuals; makes the clamping-zone rule checkable.                                                                                                                       |
| D-030               | Tilted racks: legs stand under the front/back rails; leg length = H0 + s·sinθ − hr·cosθ; default row pitch is the no-shading pitch at a 25° design sun elevation.                                                          | Standard tilt-kit geometry; the sun angle is a rule constant (conservative for the tropics).                                                                                                       |
| D-031               | Array-local → world uses basis (−u·cos ρ − v·sin ρ, n, −u·sin ρ + v·cos ρ) with the origin at the footprint's +u edge.                                                                                                     | Mapping x→u, z→v directly would be a mirror (left-handed) and flip normals; tested to cover exactly `footprintCorners()`.                                                                          |
| D-032               | Blender part scripts read their sizes from the catalog JSON.                                                                                                                                                               | One source of truth: change a clamp's frame thickness in the catalog, run `pnpm models`.                                                                                                           |
| D-033               | Instanced rendering for modules and all hardware; canvas `frameloop="demand"`.                                                                                                                                             | Few draw calls per array; zero frames when idle (measured), which also keeps software-WebGL tests fast.                                                                                            |
| D-034               | Undo merges consecutive edits of the same field within 1 s.                                                                                                                                                                | Dragging the tilt slider is one undo step, not fifty.                                                                                                                                              |
| D-035               | Inverter/battery placed in Phase 2 are procedural boxes from catalog dimensions; their Blender models come with wiring in Phase 3.                                                                                         | Their ports matter only once cables exist.                                                                                                                                                         |
| D-036               | The inspector lists every scene object as buttons.                                                                                                                                                                         | Keyboard/screen-reader selection of 3D objects (brief §10), and stable e2e selection.                                                                                                              |
| D-037               | Strings are stored as ordered module lists; series mates between modules are implicit (each + lead mates the next − lead). Home runs are explicit cables.                                                                  | Matches how installers wire (module leads plug together); avoids 2 × N cables per string.                                                                                                          |
| D-038               | Port keys are strings (`m                                                                                                                                                                                                  | array                                                                                                                                                                                              | row | col | port`, `p | part | port`); one module (`model/ports.ts`) defines them and their world positions. | Cables survive reloads and undo as plain data; a single place to change. |
| D-039               | Cold Voc uses the NEC 690.7(A)(1) coefficient method at the design low ambient; hot Vmp uses the fitted single-diode model at NOCT-estimated cell temperature on the design hot day.                                       | Brief formula for Voc; physics model where it is more accurate (linear γ−α differs by ~3 %).                                                                                                       |
| D-040               | MPPT operating point is solved by MNA with the tracker as an ideal voltage source, maximising absorbed power (golden-section).                                                                                             | Wiring losses and string mismatch come out of physics instead of fixed percentages.                                                                                                                |
| D-041               | Each cable is one conductor; a string has a + and a − home run. Loop resistance = both conductors + (N − 1 + 4) MC4 pairs × 0.5 mΩ.                                                                                        | PV wire is single-conductor; the connector count follows the physical mates.                                                                                                                       |
| D-042               | Cable ampacity for PV/battery runs uses NEC 310.16 with the design high ambient and 2 current-carrying conductors until raceways exist (Phase 5). No rooftop adder because cable routes are not yet in raceways.           | Conservative for free-air runs; Phase 5 replaces it with the real raceway fill/adder.                                                                                                              |
| D-043               | Cable routes are orthogonal standoff → x → z → vertical polylines plus 0.3 m slack per end.                                                                                                                                | Simple, predictable length estimate; real routing along rails/raceways is Phase 5.                                                                                                                 |
| D-044               | Cable-end connectors default to the opposite gender of the port's connector, same make if available; users can pick another make (mixed-brand warning).                                                                    | Brief: mixed-brand mating warning; avoids accidental male-male.                                                                                                                                    |
