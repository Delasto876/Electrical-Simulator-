# DECISIONS

Assumptions and choices, newest last. The user asked to be asked rather than
have things guessed; entries marked **(user)** were confirmed by them.

| #                | Decision                                                                                                                                    | Reason                                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 **(user)** | Build from scratch on branch `claude/trusting-hamilton-05vq5g` of `electrical-simulator-` (branch emptied first).                           | User choice. `main` untouched until merge.                                                                                                                          |
| D-002            | Use Blender, not Fusion 360, for 3D model authoring.                                                                                        | Fusion 360 has no Linux build and no headless mode; Blender runs headless via the `bpy` wheel (5.2.3 LTS on PyPI).                                                  |
| D-003 **(user)** | Hybrid models: Blender glb for fixed-shape parts, procedural three.js for spec-driven parts (panels, rails, wire, conduit, trunking, roof). | Brief §3 requires models that change with specs; glb files cannot reshape live.                                                                                     |
| D-004 **(user)** | Commit generated `.glb` files; CI never runs Blender.                                                                                       | Keeps builds fast; bpy is ~300 MB.                                                                                                                                  |
| D-005 **(user)** | Stop for review after each phase.                                                                                                           | User choice.                                                                                                                                                        |
| D-006            | Glb port markers are identified by a `port_id` extra, not by node name.                                                                     | three.js GLTFLoader sanitises node names (removes `:` `.` `/` …), which broke `port:<id>` names. Found by the Phase 0 e2e test.                                     |
| D-007            | TypeScript pinned to 6.0.x.                                                                                                                 | Latest (7.0) is not supported by typescript-eslint (peer `<6.1.0`).                                                                                                 |
| D-008            | `@playwright/test` pinned to 1.63.0.                                                                                                        | Matches the Chromium build preinstalled in the cloud container; avoids a browser download.                                                                          |
| D-009            | Workspace packages export TypeScript source (`main: src/index.ts`), no separate build step.                                                 | Vite and Vitest consume TS directly; `build` in packages is a type-check. Revisit if a package is ever published.                                                   |
| D-010            | Zod 4, Vite 8, React 19, three 0.187, R3F 9, drei 10, Zustand 5, Immer 11, Vitest 5.                                                        | Current stable versions at scaffold time; lockfile pins exact versions.                                                                                             |
| D-011            | Catalog units: dimensions in mm, port positions in m, mass in kg; field names carry the unit suffix.                                        | mm matches datasheets; metres match the 3D scene and glb exports.                                                                                                   |
| D-012            | Generic placeholder entries use brand "Generic". Branded placeholder families (Victron, Growatt, …) are **not added yet**.                  | The brief asks for them as placeholders, but invented numbers under a real brand could be read as manufacturer data. **Open question for the user** before Phase 3. |
| D-013            | MC4 gender convention on module leads: + lead = female (socket), − lead = male (pin).                                                       | Common convention; marked VERIFY because manufacturers differ. Real parts should come from datasheets.                                                              |
| D-014            | Viewport lighting uses a procedural drei `Environment` with `Lightformer`s instead of an HDR file.                                          | Metallic PBR materials render black without an environment map; Lightformers need no download, so the app stays offline-capable (PWA).                              |
| D-015            | Status colours from the Okabe–Ito colour-blind-safe palette, always paired with text/icons.                                                 | Brief §10 accessibility.                                                                                                                                            |
